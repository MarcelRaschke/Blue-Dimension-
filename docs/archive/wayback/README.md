# Wayback-Machine-Snapshots

Dieses Verzeichnis enthält gespeicherte Seiten der Internet Archive Wayback Machine. Die Dateien sind keine PHP-Seiten. Sie enthalten nur das Archive-Frontend und keinen Seiteninhalt. Sie werden nicht ausgeliefert, weil der Docroot `public/` ist.

Die Dateien stammen aus dem Initial Commit und wurden per `git mv` hierher verschoben, ohne den Inhalt zu ändern. Der echte Seiteninhalt liegt in `content/` und `public/`, siehe `docs/CONTENT.md`.
