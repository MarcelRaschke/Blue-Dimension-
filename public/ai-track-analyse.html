30Hz Heuristic Path

Input
Audio chunk (2048 samples, 48kHz) from Phase 3D buffer
Preprocessing
Normalize to [-1, 1], apply Hann window, compute magnitude spectrum (FFT)
Spectral Analysis
Centroid, spread, RMS, MFCC, chromagram, onset detection
Tonal Estimation
Key from chromagram (±1 semitone), BPM from onset tempo (±2 bpm)
Mood Mapping
Spectral centroid → mood: warm_dark | balanced | bright_energetic
Output
OSC /djjj/ai/* (key, bpm, energy, mood, source="heuristic")

Per-Track LLM Enrichment (Optional)

Trigger: Every 8–12 bars (~16s @ 120bpm) or on track change
Track Metadata

Failsafe Protocol

Philosophy: Analysis never blocks real-time DJ pipeline. On any timeout or error, fallback to heuristic immediately.

Failure Scenarios & Recovery

Scenario Detection Recovery Latency Impact
LLM Server Down Connection refused Use heuristic, log once per session Fallback < 50ms
Inference Timeout asyncio.TimeoutError after 500ms Use heuristic, retry LLM next trigger None (timeout enforced)
Network Latency Spike Response time > 500ms Discard, use heuristic None (async, non-blocking)
GPU Memory Exhaustion llama.cpp OOM message Restart llama-server, use CPU-only Degraded to 30–40 tokens/s
Librosa Library Error Exception in feature extraction Use fallback: flat spectrum, BPM=0, mood="unknown" None (cached fallback)
OSC Broadcast Failure UDP send error Log, continue analysis (cache locally) None (OSC is fire-and-forget)
