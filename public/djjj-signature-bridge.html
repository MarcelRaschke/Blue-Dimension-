Protocol Specification

OSC Message Schema (Rekordbox → TouchDesigner)

Deck State (30Hz)
/deck/1/playing int 0=stopped, 1=playing /deck/1/bpm float Current BPM (e.g., 120.5) /deck/1/beat_grid int Current beat (0-3) /deck/1/time_position float Milliseconds since start /deck/1/jog_position float Jog wheel (0.0-1.0, wraps) /deck/1/tempo_adjust float Tempo %: 1.0=100%, 1.1=+10%
Hot Cue Triggers (on-event)
/cue/1/hit int Hot cue ID (1-8) /cue/1/color int RGB packed (0xRRGGBB) /cue/1/name string Cue name ("Build", "Drop")
Master Clock (10Hz)
/master/time float Unix timestamp (seconds.frac) /master/beat int Beat counter (wraps at 4) /master/bar int Bar number

MIDI CC Mapping

CC# Parameter Range Purpose
1 Modulation (Deck 1 Jog) 0-127 Jog wheel position
2 Breath (Deck 1 Tempo) 0-127 Tempo (64=100%)
7 Channel Volume (Deck 1) 0-127 Deck 1 fader
10 Pan (Crossfader) 0-127 Left (0) → Right (127)
64-71 Hot Cue 1-8 0/127 On/off triggers

DMX512 Channel Assignment

Universe 1 (Channels 1-512)
Ch 1-9: Moving Lights (Pan/Tilt/Intensity)
Ch 10-33: 8× RGB LED Bars (R/G/B per fixture)
Ch 34-161: Video Panel 1 (128ch RGB PWM)
Ch 162-289: Video Panel 2 (128ch RGB PWM)
Ch 290-417: Video Panel 3 (128ch RGB PWM)
Ch 418-512: Video Panel 4 + Reserved

Implementation Guide

TouchDesigner OSC Setup

Configure OSC listener on UDP port 6969 with Python callback:

def messageReceived(args, argString): addr = args[0] if addr == '/deck/1/bpm': bpm = args[1] op('chop_bpm').val = bpm elif addr == '/cue/1/hit': triggerCueAnimation(args[1]) elif addr == '/master/time': op('chop_sync_time').val = args[1]

Production Deployment

Pre-Show Checklist (30 min)

  • Network connectivity verified (all devices on same subnet)
  • Rekordbox → OSC bridge running and logging
  • TouchDesigner listening on UDP :6969
  • DMX USB adapter recognized by OS
  • Beat sync test: Play track, verify counter in TD
  • Cue trigger test: Hit hot cue, watch animation
  • DMX test: Manually set channels, observe lighting

Failsafe Protocols

Failure Cause Mitigation
