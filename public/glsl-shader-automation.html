  ↓ [Render pass]

  ↓

Shader Template: Base Compute Kernel

#version 430 core layout(local_size_x = 256) in; layout(std430, binding = 0) buffer ParticleBuffer { vec4 position[]; // xyz: pos, w: life (0–1) vec4 velocity[]; // xyz: vel, w: mass vec4 color[]; // rgba }; uniform float u_freq[8]; // Frequency bins uniform float u_energy; // RMS energy (0–1) uniform float u_beat_phase; // Beat phase (0–1) uniform float u_time; // Global time void main() { uint idx = gl_GlobalInvocationID.x; if (idx >= 5000) return; // Particle count vec3 pos = position[idx].xyz; vec3 vel = velocity[idx].xyz; float life = position[idx].w; // Physics: gravity + frequency-driven acceleration vec3 accel = vec3(0, -0.01, 0); accel.xz += vec3(cos(pos.y * 10.0), sin(pos.y * 10.0)) * u_freq[2] * 0.5; vel += accel * 0.016; // 60 Hz timestep vel *= 0.98; // Drag pos += vel * 0.016; // Boundary wrap if (pos.y < -5.0) { pos = vec3(rand() * 4.0 - 2.0, 3.0, rand() * 4.0 - 2.0); life = 1.0; } life -= 0.01; // ~100 frames to live // Write back position[idx] = vec4(pos, max(0.0, life)); velocity[idx] = vec4(vel, velocity[idx].w); }

Failsafe Protocols

GPU Temp > 85°C
Reduce particles: 5000 → 2000 | Log warning | Monitor next 10s
OSC Timeout > 500 ms
Switch to idle_shader.glsl (slow drift) | Preserve framerate | Resume on OSC recovery
Framerate < 30 FPS
Disable compute shader | Render static texture buffer | Alert operator
GPU Memory Exhausted
Release particle pool | Fall back to 500-particle minimum | Degrade gracefully
Shader Compile Error
Load fallback_default.glsl (solid color + subtle animation) | Log GLSL errors | Continue playback
Bridge Crash (no FFT)
Use static frequency curve | Continue at reduced reactivity | Wait for Bridge recovery

Emergency Procedure

  1. GPU Thermal Shutdown: Kill compute shader, fall back to static render (0 latency increase)
  2. Bridge Crash: TouchDesigner continues with last-known OSC state for 30s before idle fallback
  3. Frame Drop Below 30 FPS: Entire compute disabled; display last frame buffer (frozen visuals but no stutter)
  4. Complete System Failure: Hard fade to black + ambient music; no visual output > 2s of audio
