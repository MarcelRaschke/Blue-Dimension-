Real-Time Parameter Binding

Phase 3D → Phase 4B Particle Parameters
freq_bins[0..7] → Particle acceleration (per spatial axis) RMS energy → Particle size + alpha Bar/Beat counter → Spawn sync + light animation MIDI Key (0–11) → HSV hue mapping
Phase 4A → Phase 4C GPU Uniforms
energy (0–100) → scattering_coeff = 0.1 + (energy / 100) * 0.9 mood (string) → absorption_coeff: energetic=0.3, warm=0.8, balanced=0.5 spectral_centroid → light_color RGB mapping <2kHz: (1.0, 0.6, 0.2) warm 2–4kHz: (1.0, 0.8, 0.6) balanced >4kHz: (1.0, 1.0, 0.8) bright
Phase 4B → Phase 4C Density Field
Particle SSBO → Input to density compute shader Positions + Radius → Gaussian contributions per voxel Lifetime → Fade parameter (older particles less dense) Output: 3D texture 64³ (updated every frame)
Phase 4C → Display / Compositing
Ray-march output → Volumetric lighting texture (HDR) Particle layer → Phase 4B additive base Depth layer → Focus distance from bar counter Final: composite + tone-map + optional bokeh

Failsafe Thresholds
